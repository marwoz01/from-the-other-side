# From the Other Side

**From the Other Side** is a simple Node.js project that allows users to submit and read paranormal stories.  
The application focuses on backend fundamentals and safe data handling.

## What was covered in this project

- **Node.js FS module**
  - Reading data from files
  - Writing and updating files

- **Path module**
  - Creating safe and portable file and directory paths

- **Serving static assets**
  - Delivering static files (HTML, CSS, assets) via a Node.js server

- **Dependencies**
  - Installing and using external packages
  - Managing project dependencies

- **Input sanitization**
  - Cleaning user-submitted data
  - Preventing unsafe or malicious input

## Technologies

- Node.js
